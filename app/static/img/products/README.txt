Drop Motion Impossible product photos here (JPG, PNG, WEBP or GIF).

The footer shows a random one as a "Field kit sighting". The caption comes from the file name,
with hyphens and underscores turned into spaces, so name the files how you want them captioned.
For example, "dolly_on-set.jpg" is captioned "dolly on set".

Only use images you're happy to show on the office network. Keep each under ~500 KB so phones
load them quickly.
